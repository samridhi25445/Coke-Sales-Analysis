# 🥤 Coke Sales Analysis — Excel

## 📌 Project Overview

This project analyzes **Coca-Cola beverage sales data** using Microsoft Excel to identify sales trends, regional performance, beverage brand performance, retailer contribution, and unit sales patterns.

The analysis uses sales data from **2021** and applies Excel-based data cleaning, calculations, PivotTables, and visualizations to transform raw sales data into meaningful business insights.

---

## 🎯 Business Objective

The objective of this project is to analyze beverage sales performance and answer key business questions such as:

* How do sales change month over month?
* Which beverage brands generate higher sales?
* Which regions contribute the most to sales?
* Which retailers have higher unit sales?
* How do beverage brands perform across different regions?
* What patterns can be observed in monthly unit sales?
* How can sales and profitability data support business decision-making?

---

## 📊 Dataset

The dataset contains beverage sales and operating information for key American Coca-Cola retailers.

### Key Columns

| Column           | Description                       |
| ---------------- | --------------------------------- |
| Retailer         | Retailer name                     |
| Retailer ID      | Unique retailer identifier        |
| Invoice Date     | Date of the transaction           |
| Region           | Sales region                      |
| State            | State of operation                |
| City             | City of operation                 |
| Beverage Brand   | Coca-Cola beverage brand          |
| Price per Unit   | Selling price per unit            |
| Units Sold       | Number of units sold              |
| Total Sales      | Total sales/revenue               |
| Operating Profit | Operating profit                  |
| Operating Margin | Operating margin percentage       |
| Month            | Extracted month from invoice date |
